# ROADMAP.md

## Current Status

- Phase 1 complete
- Phase 2 complete
- Phase 3 complete
- Phase 4 is the next major system build track

## Phase 1: Documentation Foundation

Goal:
Create the full documentation foundation for the Helios Agent System.

Possible features:
- Core system docs
- Agent role definitions
- Routing docs
- Workflow docs
- Templates
- Project briefs

Success definition:
The repo clearly explains every agent, routing logic, build philosophy, and project direction.

What not to overbuild yet:
Do not build apps, integrations, or backend systems in this phase.

## Phase 2: Core Boys International Tracker

Status:
Complete

Goal:
Build the first simple Core Boys working tracker.

Possible features:
- Add content idea
- View content ideas
- Filter by creator/platform/status
- Basic KPI cards
- Empty state
- Mobile-friendly layout

Success definition:
The user can track Core Boys ideas and basic performance in one practical tool.

What not to overbuild yet:
No real database, no authentication, no scraping, no complex backend.
