# Full Agent Workflows

This file explains how multiple agents should work together without overbuilding.

## Workflow 1: Building a New System

Use when the user wants a new dashboard, tracker, Notion hub, or tool.

1. Helios clarifies the outcome.
2. Strategos sets priority and scope.
3. Achilles defines the system structure.
4. Atlas fills any missing context.
5. Forge builds the smallest useful implementation.
6. Helios summarizes what was built and what comes next.

## Workflow 2: Core Boys International

1. Helios receives the request.
2. Kirin generates hooks and content angles.
3. Atlas researches references or trends.
4. Strategos picks weekly focus and tradeoffs.
5. Achilles structures the Notion workflow.
6. Forge builds tracker/tool support.
7. Helios gives the final plan and next actions.

## Workflow 3: Finance and Investing

1. Helios receives the finance request.
2. Midas analyzes numbers, risk, and options.
3. Atlas retrieves supporting sources if needed.
4. Strategos helps decide priority actions.
5. Forge builds simple finance tools if needed.
6. Helios returns final recommendation and next step.

## Workflow 4: Health, Meals, and Routines

1. Helios receives the request.
2. Vitalis builds a realistic health or routine plan.
3. Strategos schedules and prioritizes execution.
4. Achilles organizes templates or Notion systems if needed.
5. Forge builds calculators or trackers if needed.
6. Helios summarizes final steps.

## Workflow 5: Research Projects

1. Helios defines the research objective.
2. Atlas gathers and organizes sources.
3. Strategos structures findings into decisions.
4. Kirin adds creative framing if needed.
5. Achilles formats the final research system.
6. Helios delivers summary and next action.

## Workflow 6: Creative Projects

1. Helios defines the creative goal.
2. Kirin generates and groups ideas.
3. Strategos ranks highest-leverage options.
4. Atlas retrieves reference material if needed.
5. Achilles structures ideas into a usable system.
6. Forge builds tools/templates/prototypes if needed.
7. Helios gives final direction.

## Workflow 7: Weekly Planning

1. Helios receives weekly goals and constraints.
2. Strategos builds the priority plan.
3. Midas/Vitalis/Kirin contribute domain inputs as needed.
4. Achilles organizes the planning format.
5. Helios returns final weekly plan with next actions.

## Workflow 8: Notion Builds

1. Helios confirms the objective.
2. Achilles designs pages, databases, and workflow structure.
3. Strategos validates priority and sequencing.
4. Atlas fills missing reference context.
5. Forge builds supporting scripts/tools only if needed.
6. Helios summarizes the final system.

## Workflow 9: Tool or App Builds

1. Helios defines the user outcome.
2. Strategos enforces MVP scope.
3. Achilles maps required workflow and fields.
4. Forge builds the technical MVP.
5. Atlas validates information inputs when needed.
6. Helios reviews output and defines the next safest step.

## Workflow 10: External Second-Opinion Pass (Claude)

Use when Helios wants stronger writing clarity, synthesis quality, or alternative framing.

1. Helios defines the goal, constraints, and draft/output to review.
2. Claude provides advisory feedback: what to keep, what to improve, and why.
3. Helios selects what feedback to adopt.
4. Achilles updates Notion/system docs if needed.
5. Forge implements technical or repo-level changes if needed.
6. Helios gives the final version and next step.

## Workflow 11: Career and Job Search

1. Helios confirms the career objective and timeline.
2. Orion drafts the resume/application/interview workflow.
3. Strategos prioritizes role targets and sequence.
4. Atlas gathers company and role context when needed.
5. Achilles structures the Notion tracking system.
6. Forge builds helper tooling only if recurring friction is proven.
7. Helios closes with final weekly career plan and next actions.
