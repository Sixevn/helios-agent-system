# Workflows

This file is a short workflow index for the Helios Agent System.

Primary routing source:
- `docs/agent-routing-system.md`

Full multi-agent workflow details:
- `docs/full-agent-workflows.md`

## Default Helios Routing Workflow

1. Helios receives the request.
2. Helios identifies the request type.
3. Helios routes to the best-fit agent.
4. If multiple agents are needed, Helios sequences the handoff.
5. Helios returns the final practical summary and next step.

## Build Workflow

1. Helios clarifies the outcome.
2. Strategos keeps scope tight.
3. Achilles structures systems/workflows when needed.
4. Forge builds the technical implementation.
5. Atlas fills missing reference context if needed.
6. Helios summarizes what changed and what is next.

## Notion Workflow

1. Helios confirms the system goal.
2. Achilles designs the Notion structure.
3. Strategos checks priority and scope.
4. Atlas adds research context if needed.
5. Forge builds support tools only if required.
6. Helios gives the final structured result.

## Research Workflow

1. Helios defines the research objective.
2. Atlas retrieves and organizes sources.
3. Strategos structures findings into decisions.
4. Kirin helps framing if creativity is needed.
5. Achilles formats output into a reusable system.
6. Helios summarizes the final brief.

## Finance Workflow

1. Helios receives the finance request.
2. Midas analyzes numbers, risk, and options.
3. Atlas retrieves supporting data when needed.
4. Strategos prioritizes decision paths.
5. Forge builds a tracker/calculator only if useful.
6. Helios returns the final recommendation.

## Health and Routine Workflow

1. Helios receives the health or routine request.
2. Vitalis creates the practical plan.
3. Strategos schedules and prioritizes execution.
4. Achilles organizes templates or system structure if needed.
5. Forge builds a supporting tool only if useful.
6. Helios gives final next steps.

## Strategy Workflow

1. Helios defines the target decision.
2. Strategos builds the priority framework.
3. Atlas provides facts and context.
4. Domain agents (Midas, Vitalis, Kirin, or others) add specialist input.
5. Helios finalizes the decision path and next action.

## Creative Workflow

1. Helios defines the creative objective.
2. Kirin generates concepts and hooks.
3. Strategos ranks options by usefulness.
4. Atlas gathers references if needed.
5. Achilles organizes ideas into a system.
6. Forge builds a prototype/template if needed.
7. Helios returns the final direction.

## Career Workflow

1. Helios confirms the career target and timeline.
2. Orion drafts the resume/application/interview workflow.
3. Strategos ranks role priorities and weekly focus.
4. Atlas gathers company and role context if needed.
5. Achilles organizes career tracking structure.
6. Forge builds helper tooling only if recurring friction is proven.
7. Helios returns the final plan and next step.

## Tool and App Workflow

1. Helios confirms the user outcome.
2. Strategos enforces MVP scope.
3. Achilles maps workflow and data structure.
4. Forge builds the smallest useful tool/app.
5. Atlas validates supporting references if needed.
6. Helios summarizes implementation and next step.

## Weekly Review Workflow

1. Helios sets the weekly review objective.
2. Strategos defines top priorities and tradeoffs.
3. Domain agents provide section inputs:
   - Kirin for ideas and hooks
   - Atlas for source trends and context
   - Midas for finance checks
   - Vitalis for routine/health checks
4. Achilles organizes the weekly review structure.
5. Forge builds or updates support tooling if needed.
6. Helios gives the final weekly plan.

Core Boys remains the first build target, but weekly review workflows should support the full agent system over time.
