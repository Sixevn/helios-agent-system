# Pattern Ops Today Runbook (15-20 Minutes)

Use this for daily execution during pilot week. Keep it strict and short.

## Minute 0-2: Open and Align

1. Open:
`docs/pattern-ops-pilot-status.md`
2. Open:
`docs/pattern-ops-day1-intake-prefilled.md`
3. Pick one top priority opportunity for today.

## Minute 2-6: Confirm Signal Validity

1. Re-check date windows and trigger timing.
2. Confirm at least 2 sources are still valid.
3. If timing shifted materially, mark `Hold` and move to next opportunity.

## Minute 6-10: Lock One Action

1. Write exactly one action for today:
- one brief,
- one content batch slice,
- or one test setup.
2. Define win threshold and one kill switch from the intake entry.
3. Set owner and deadline for today.

## Minute 10-14: Execute in System

1. Log today action in your working tracker.
2. If content/test related, update Core Boys Tracker with real entries.
3. Keep execution scope small enough to finish today.

## Minute 14-17: Friction Capture

1. Open:
`docs/pattern-ops-friction-capture-prompts.md`
2. Capture at least one friction note if anything slowed you down.
3. Label friction severity: S1 (blocker), S2 (major), S3 (minor).

## Minute 17-20: Close Day

1. Update Day row in:
`docs/pattern-ops-pilot-status.md`
2. Fill:
- Top Win
- Main Blocker
- Next Action
3. If blocker repeats twice, create a repo improvement ticket immediately.

## Daily Exit Criteria

- One opportunity advanced by one concrete step.
- One measurable result or decision logged.
- Pilot status row updated.
