# Pattern Ops Signal Source Map

Use this map to keep Pattern Ops grounded in reliable, repeatable signal sources.

## Source Reliability Tiers

- Tier 1: Official primary sources (regulators, exchanges, platform docs, event organizers)
- Tier 2: Major institutional secondary sources (large index/news providers)
- Tier 3: Community and commentary sources (use only for idea discovery, not decision proof)

Decision rule:
- Validate and Execute stages require at least one Tier 1 source.

## Atlas Validation Checklist

Before moving an opportunity from Validate to Score, confirm:

- Source recency is acceptable for the pattern window.
- At least one Tier 1 source is present.
- Trigger date/range is explicit.
- Any estimated dates are labeled as estimated.
- Contradictory sources are logged and resolved.

## Helios Decision Gate

If no Tier 1 source exists, Helios should mark the opportunity Hold or Research-Only, not Execute.
