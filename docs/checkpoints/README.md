# Checkpoint Artifact Path

This folder is the canonical output path for weekly Core Boys checkpoint decision artifacts.

Naming standard:
- `YYYY-MM-DD-core-boys-weekly-checkpoint-summary.md`

Minimum required sections:
1. Week Window
2. Data Readiness
3. Baseline vs Current Metrics
4. Tracker Context
5. Helios Decision Block (with confidence)

Policy:
- Local markdown remains canonical in v1.
- Generated artifacts support decision speed, but do not bypass Helios final gate.
