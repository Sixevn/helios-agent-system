# Strategos Planning System

## Purpose

The Strategos Planning System helps with priorities, weekly planning, tradeoffs, and execution.

## Use Cases

- Weekly planning
- Choosing what to do first
- Comparing options
- Time blocking
- Project prioritization
- Goal planning
- Decision logs

## MVP Ideas

A future Strategos tool could include:
- Weekly priority planner
- Decision matrix
- Tradeoff tracker
- Goal tracker
- Project priority board
- Daily execution checklist

## Fields

- Goal
- Deadline
- Priority
- Effort level
- Impact level
- Risk
- Next action
- Related agent
- Related project
- Status

## Do Not Build Yet

Do not build a full productivity app until the user has tested smaller planning templates.
