# Atlas Research System

## Purpose

The Atlas Research System helps organize research, sources, summaries, files, and project context.

## Use Cases

- Research current trends
- Summarize articles
- Summarize uploaded files
- Build source lists
- Create briefing docs
- Compare sources
- Map a Notion workspace or project folder

## MVP Ideas

A future Atlas tool could include:
- Research brief template
- Source tracker
- File summary tracker
- Key facts table
- Open questions list
- Citation notes
- Project research map

## Fields

- Research topic
- Source name
- Source link
- Date accessed
- Key takeaways
- Important quotes
- Reliability notes
- Related project
- Open questions

## Do Not Build Yet

Do not build a full research database until Core Boys, Midas, and Vitalis MVPs are clearer.
