# Midas Finance Dashboard

## Project Purpose

The Midas Finance Dashboard is a future tool for personal finance, budgeting, loans, investing, and financial analysis.

## Core Features

Potential features:
- Budget tracker
- Subscription tracker
- Student loan tracker
- Net worth snapshots
- Cash flow review
- Stock watchlist
- Fundamental analysis notes
- Technical analysis notes
- Risk score
- Important market dates
- Personal finance decision log

## MVP Fields

Start with:
- Account or category name
- Type
- Monthly amount
- Due date
- Priority
- Notes

## Future Features

- Loan payoff calculator
- Investment watchlist
- Ticker report template
- Cash flow dashboard
- Net worth trend
- Risk dashboard
- Earnings calendar tracker

## Rule

Midas should separate facts, assumptions, and opinions.

Do not build this before the Core Boys tracker foundation is working.
