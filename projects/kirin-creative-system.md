# Kirin Creative System

## Purpose

The Kirin Creative System helps generate, organize, and refine creative ideas.

## Use Cases

- Content hooks
- Brand ideas
- Project names
- Video concepts
- Journaling prompts
- Reflection
- Creative brainstorming
- Campaign concepts

## MVP Ideas

A future Kirin tool could include:
- Hook generator
- Idea bank
- Brand concept board
- Creative prompt library
- Content angle tracker
- Reflection journal template

## Fields

- Idea name
- Category
- Related project
- Hook
- Concept
- Target audience
- Platform
- Strengths
- Weaknesses
- Next action
- Status

## Do Not Build Yet

Do not build a full creative app before the Core Boys content tracker is working.
