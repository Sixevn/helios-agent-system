# Vitalis Meal Planner

## Project Purpose

The Vitalis Meal Planner is a future tool for meals, groceries, servings, protein planning, routines, and recovery.

## Core Features

Potential features:
- Meal prep calculator
- Family serving calculator
- Grocery list generator
- Protein day planner
- Recovery review
- Weekly routine planner
- Sleep routine tracker

## MVP Fields

Start with:
- Meal name
- Servings needed
- People eating
- Days covered
- Ingredients
- Protein source
- Prep time
- Notes

## Example Use Case

The user wants to cook enough food for themselves and family from Monday lunch through Tuesday dinner, then cook something else Wednesday.

The planner should calculate:
- Number of meals
- Number of servings
- Grocery amounts
- Storage notes
- Reheating notes

## Rule

Vitalis should keep health and meal advice realistic and simple.

Do not build this before the Core Boys tracker foundation is working.
