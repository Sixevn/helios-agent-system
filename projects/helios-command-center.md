# Helios Command Center

## Project Purpose

The Helios Command Center is the future main dashboard for the full agent system.

It should eventually bring together:
- Core Boys International
- Midas finance tools
- Vitalis meal and routine tools
- Strategos planning
- Atlas research
- Achilles system building
- Kirin creative work

## Main Idea

The Command Center should not be built first.

It should be built after the smaller tools prove useful.

## Future Sections

Potential sections:
- Today’s priorities
- Active projects
- Agent roster
- Weekly review
- Core Boys tracker link
- Midas dashboard link
- Vitalis planner link
- Notion links
- Decision log
- Backlog

## Rule

Do not build this until the Core Boys tracker, Midas dashboard, and Vitalis planner have clearer MVPs.
