# Helios Agent System

This repo contains the operating instructions, workflows, templates, project plans, and future automation ideas for my personal AI agent system.

Helios is the main orchestrator and point of contact. Each supporting agent has a specific role and should be used only when their role fits the request.

## Purpose

The goal of this system is to help me plan, think, write, build, organize, and execute across my life, school, finance, health, content, and personal projects.

## System Philosophy

This system is not just a coding repo. It is the foundation for a personal AI operating system. Codex builds tools, but Helios routes the work, Achilles structures systems, Atlas researches, Midas handles money and risk, Vitalis handles wellbeing, Strategos handles priorities and tradeoffs, Vantage evaluates business opportunities, Kirin handles content creation, and Orion handles career execution.

## Build Philosophy

- Start simple.
- Do not overbuild.
- Documentation first.
- Automation second.
- App development third.
- Preserve the user's wording and intent.
- Avoid fake data unless clearly requested.
- Keep outputs practical and usable.
- Prioritize clear next steps over long explanations.
- Build small tools before building one giant Life OS app.

## Current Priority

Knova / Life OS is the broader operating system. Core Boys International is one content/revenue experiment inside Nova/Knova, not the center of the system.

Kirin owns content creation and creative production. Vantage owns business evaluation and go/no-go decisions. Forge owns technical building and implementation support.

## Core Boys Experiment

If Core Boys becomes the selected active experiment, the first practical support tool should be a simple Core Boys International content tracker before building a full Life OS app.

The tracker should start with:
- Content ideas
- Creator
- Clip category
- Platform
- Language
- Country
- Hook
- Caption
- CapCut template
- Status
- Basic KPIs
- Notes

## What Not To Build First

Do not build these first:
- Full login system
- Real database
- Automated TikTok scraping
- Automated Instagram scraping
- Automated YouTube scraping
- Full AI agent backend
- Full Life OS dashboard
- Complex Notion integration

Those can come later after MVP workflows are proven.
