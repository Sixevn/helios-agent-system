# Helios Agent System

This repo contains the operating instructions, workflows, templates, project plans, and future automation ideas for my personal AI agent system.

Helios is the main orchestrator and point of contact. Each supporting agent has a specific role and should be used only when their role fits the request.

## Purpose

The goal of this system is to help me plan, think, write, build, organize, and execute across my life, school, finance, health, content, and personal projects.

## System Philosophy

This system is not just a coding repo. It is the foundation for a personal AI operating system. Codex builds tools, but Helios routes the work, Achilles structures systems, Atlas researches, Midas handles finance, Vitalis handles wellbeing, Strategos handles decisions, Kirin handles creativity, and Orion handles career execution.

## Build Philosophy

- Start simple.
- Do not overbuild.
- Documentation first.
- Automation second.
- App development third.
- Preserve the user's wording and intent.
- Avoid fake data unless clearly requested.
- Keep outputs practical and usable.
- Prioritize clear next steps over long explanations.
- Build small tools before building one giant Life OS app.

## Current Priority

Core Boys International is the first practical build target because it has the clearest near-term path toward content planning, analytics, automation, and monetization.

Core Boys is the first build, not the only system. The Helios repo supports the full agent team and multi-project roadmap.

## First Practical Build Target

The first practical tool should be a simple Core Boys International content tracker before building a full Life OS app.

The tracker should start with:
- Content ideas
- Creator
- Clip category
- Platform
- Language
- Country
- Hook
- Caption
- CapCut template
- Status
- Basic KPIs
- Notes

## What Not To Build First

Do not build these first:
- Full login system
- Real database
- Automated TikTok scraping
- Automated Instagram scraping
- Automated YouTube scraping
- Full AI agent backend
- Full Life OS dashboard
- Complex Notion integration

Those can come later after MVP workflows are proven.
